# telling-web

A frontend web version of **Telling**, an anonymous confession and audio-room app.

## Tech Stack
- HTML5
- CSS3 (Flexbox, Grid, CSS variables)
- Vanilla JavaScript

## Status
🚧 In progress. Frontend only, using dummy data.

## Planned Pages
- Splash, Login, Sign up
- Home (confession feed)
- Confession Rooms and Room screen
- Create Confession
- Friend Requests, Friends, Anonymous Inbox
- Profile and Golden Hearts
